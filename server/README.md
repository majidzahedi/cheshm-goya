# سرور هوش مصنوعی چشم‌گویا (`server/`)

این سرور یک **لایه‌ی اختیاری** است. اپ تبلت بدون آن کامل کار می‌کند. اگر سرور خاموش یا در دسترس نباشد، اپ بی‌صدا به پیش‌بینی آفلاین برمی‌گردد.

همه‌چیز روی کامپیوتر خودتان اجرا می‌شود. هیچ درخواستی به سرویس اینترنتی فرستاده نمی‌شود. اینترنت فقط یک بار برای دانلود مدل‌ها لازم است.

## راه‌اندازی

```bash
cd server
# ۱. بررسی سخت‌افزار و انتخاب مدل‌ها بر اساس VRAM (فایل .env را می‌سازد)
python3 scripts/detect_hardware.py --write-env

# ۲. دانلود یک‌باره‌ی مدل‌ها در ./models (رتبه‌بند، Whisper، صداهای Piper)
pip install huggingface_hub && python3 scripts/download_models.py

# ۳. مدل زبانی در Ollama
docker compose up -d ollama
docker compose exec ollama ollama pull "$(grep CG_LLM_MODEL .env | cut -d= -f2)"

# ۴. اجرای سرور
docker compose up -d --build api

# ۵. اتصال تبلت: روی همین کامپیوتر باز کنید و QR را جلوی دوربین تبلت بگیرید
xdg-open http://localhost:8765/pair      # یا: docker compose exec api python3 -m app.pairing
```

پیش‌نیازها: Docker، درایور NVIDIA و NVIDIA Container Toolkit. در ویندوز از WSL2 با Docker Engine استفاده کنید. برای mDNS شبکه‌ی host لازم است.

## Endpointها

همه‌ی Endpointها به‌جز `/pair` هدر `Authorization: Bearer <token>` می‌خواهند.

| مسیر | کار |
|---|---|
| `POST /complete` | کامل کردن جمله: ۳ پیشنهاد کوتاه، محاوره‌ای و اول‌شخص (ورودی: متن تایپ‌شده، ۵ پیام اخیر، ساعت) |
| `POST /rank` | رتبه‌بندی عبارت‌ها با احتمال و confidence (روش openjev، پایین‌تر توضیح داده شده) |
| `POST /classify` | نوع سؤال همراه بیمار (`yes_no`/`choice`/`open`) و موضوع آن (`needs`/`pain`/`feelings`/`people`) |
| `POST /stt` | گفتار به متن با Whisper (فرم multipart با فیلد `audio`) |
| `POST /tts` | متن به صدا (WAV)، با انتخاب صدا |
| `GET /voices` | فهرست صداها |
| `POST /voice/enroll` | بانک صدا: ذخیره‌ی فایل‌های صوتی بیمار برای ساخت صدای شخصی |
| `POST /personalize/sentences` | همگام‌سازی جمله‌های بیمار، فقط اگر خانواده در اپ اجازه داده باشد |
| `GET /health` | وضعیت سرور و مدل‌ها |
| `GET /pair` | صفحه‌ی QR برای اتصال. فقط از خود همین کامپیوتر باز می‌شود |

## انتخاب مدل‌ها (جست‌وجو در سپتامبر ۲۰۲۶)

`scripts/detect_hardware.py` کارت گرافیک، VRAM، RAM و سیستم‌عامل را با `nvidia-smi` بررسی می‌کند و یکی از ردیف‌های زیر را انتخاب می‌کند:

| VRAM | مدل زبانی (Ollama) | رتبه‌بند | Whisper |
|---|---|---|---|
| ≥ ۳۲ GB | `qwen3.5:27b` | `Qwen/Qwen3-4B` | `large-v3` (float16) |
| ۱۲ تا ۳۲ GB | `qwen3.5:9b` | `Qwen/Qwen3-1.7B` | `large-v3-turbo` (float16) |
| ۸ تا ۱۲ GB | `qwen3.5:4b` | `Qwen/Qwen3-1.7B` | `large-v3-turbo` (int8_float16) |
| ۵ تا ۸ GB | `qwen3.5:2b` | `Qwen/Qwen3-0.6B` | `large-v3-turbo` (int8_float16) |
| بدون GPU | `qwen3.5:2b` | `Qwen/Qwen3-0.6B` | `small` (int8، روی CPU) |

دلیل انتخاب‌ها:

- **مدل زبانی: خانواده‌ی Qwen.** در بنچمارک‌های فارسی (PARSE و مقایسه‌های TARAZ) مدل‌های Qwen بهترین نتیجه را بین مدل‌های متن‌باز داشتند. Qwen3 رسماً از بیش از ۱۰۰ زبان پشتیبانی می‌کند. Qwen3.5 (فوریه‌ی ۲۰۲۶) از 0.8b تا 122b در Ollama موجود است و مجوز Apache 2.0 دارد. گزینه‌ی دوم Gemma 4 (مارس ۲۰۲۶) است که با `CG_LLM_MODEL` قابل تعویض است.
- **سرعت از اندازه مهم‌تر است:** پیشنهادها باید در کمتر از ۳ ثانیه برسند. برای همین روی کارت ۲۴ گیگابایتی مدل 9b انتخاب شده، نه 27b.
- **رتبه‌بند:** یک مدل کوچک Qwen3 با Transformers، چون روش openjev به logits مستقیم نیاز دارد و Ollama آن را در اختیار نمی‌گذارد.
- **Whisper:** نسخه‌ی `large-v3-turbo` سریع است و فارسی را خوب می‌فهمد. مدل‌های fine-tune‌شده روی فارسی هم هست (مثلاً `oi-uae/farsi-faster-whisper-large-v3`). با `CG_WHISPER_MODEL` می‌توانید آن را امتحان کنید.
- **TTS:** صداهای فارسی Piper (`fa_IR-amir`، `gyro`، `reza_ibrahim`، `ganji`). سبک، کاملاً محلی، و روی CPU هم سریع.

> ⚠️ نام دقیق برچسب‌های Ollama (مثل `qwen3.5:9b`) را قبل از `ollama pull` در ollama.com/library بررسی کنید. من نتوانستم از این محیط به رجیستری Ollama وصل شوم.

## رتبه‌بندی به روش openjev

این روش متن تولید نمی‌کند. احتمال هر گزینه را مستقیم از logits یک مدل کوچک می‌خواند (`app/services/ranker.py`):

1. **likelihood:** همه‌ی عبارت‌های نامزد به یک context مشترک اضافه می‌شوند و در **یک forward pass دسته‌ای** امتیاز می‌گیرند (میانگین log-prob توکن‌ها). padding از چپ است، پس فقط logits چند موقعیت آخر محاسبه می‌شود و حافظه کم مصرف می‌شود.
2. **choice:** چند گزینه‌ی برتر با حروف A تا F فهرست می‌شوند. توزیع احتمال از logits توکن بعدی، فقط روی همان حروف، خوانده می‌شود. این مثل `Choice` در Jev است که فقط روی گزینه‌های داده‌شده softmax می‌گیرد.

`confidence` بیشترین احتمال در مرحله‌ی دوم است. اپ فقط وقتی ردیف «پیشنهادها» را پر می‌کند که confidence از آستانه‌ی تنظیم‌شده بالاتر باشد.

## شخصی‌سازی

- جمله‌های بیمار فقط با اجازه‌ی صریح در تنظیمات اپ همگام می‌شوند و در `data/personal.db` روی همین کامپیوتر می‌مانند.
- **few-shot:** در هر درخواست، جمله‌های مشابه قبلی (شباهت سه‌حرفی) و جمله‌های پرتکرار در prompt گذاشته می‌شوند.
- **LoRA (اختیاری):** وقتی داده‌ی کافی جمع شد (پیش‌فرض ۳۰۰ جمله):
  `pip install -r requirements-finetune.txt && python3 scripts/finetune_lora.py`.
  این اسکریپت رتبه‌بند را روی جمله‌های خود بیمار تنظیم می‌کند.

## شبیه‌سازی صدا (Voice Banking): گزارش صادقانه

نتوانستم مدل متن‌باز شبیه‌سازی صدایی پیدا و **آزمایش** کنم که کیفیت خروجی فارسی‌اش برای صدای شخصی بیمار قابل‌قبول باشد. از این محیط به Hugging Face دسترسی نداشتم و GPU هم نبود که نمونه بسازم و گوش بدهم. نامزدهایی که پیدا شد:

- `persian_tts` (pocket-tts-farsi، روی CPU و با شبیه‌سازی صدا)
- fine-tuneهای فارسی F5-TTS

کیفیت هیچ‌کدام تأیید نشده است. پس:

- `POST /voice/enroll` **پیاده شده**: فایل‌های صوتی بیمار (پیام‌های صوتی قدیمی، ویدیوها و …) روی همین کامپیوتر ذخیره و مدتشان محاسبه می‌شود. برای بیماران ALS ضبط صدا تا وقتی هنوز ممکن است ارزشمند است.
- `/tts` با صدای `personal-…` فعلاً به صدای طبیعی Piper برمی‌گردد و این را با هدر `X-Voice-Fallback: default` اعلام می‌کند.
- هر وقت مدل مناسبی انتخاب و آزمایش شد، از طریق `CloneBackend` در `app/services/voice.py` اضافه می‌شود.

## امنیت و حریم خصوصی

- **توکن مشترک:** بار اول ساخته و در `data/token` ذخیره می‌شود (مجوز 600). مقایسه‌ی آن در زمان ثابت انجام می‌شود.
- **فقط شبکه‌ی محلی:** درخواست‌هایی که از آدرس غیرخصوصی بیایند رد می‌شوند. آدرس‌های مجاز: `10/8`، `172.16/12`، `192.168/16`، Tailscale (`100.64/10`) و loopback. هیچ پورتی را روی روتر forward نکنید. برای دسترسی از بیرون خانه از **Tailscale** استفاده کنید و `CG_PUBLIC_HOST` را روی IP تیل‌اسکیل بگذارید.
- **Ollama** فقط روی `127.0.0.1` گوش می‌دهد.
- **صفحه‌ی QR و توکن** فقط از خود کامپیوتر سرور باز می‌شود.
- **mDNS** فقط شناسه‌ی سرور را اعلام می‌کند، نه توکن.
- **بدون ارسال به بیرون:** در زمان اجرا `HF_HUB_OFFLINE=1` است.
- **لاگ‌ها** متن پیام‌ها را ذخیره نمی‌کنند، فقط طول آن‌ها را. مگر با `CG_LOG_MESSAGE_TEXT=true`.
- **HTTP ساده:** اتصال تبلت به سرور روی شبکه‌ی محلی HTTP است. روی Wi-Fi مشترک یا ناامن، از Tailscale استفاده کنید تا ارتباط رمزنگاری شود.
