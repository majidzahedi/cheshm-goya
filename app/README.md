# اپ اندروید چشم‌گویا (`app/`)

Kotlin + Jetpack Compose، minSdk 26، معماری MVVM.

| ماژول | محتوا |
|---|---|
| `core/` | منطق خالص Kotlin با unit test: تشخیص پلک، کالیبراسیون، نگاه، اسکنر، پیش‌بینی متن، صفحه‌کلید، بانک عبارت‌ها، لایه‌ی `AiProvider` (آفلاین، سرور محلی، Jev) |
| `ai-claude/` | `ClaudeProvider` با SDK رسمی Java شرکت Anthropic (ماژول JVM، با تست) |
| `android/` | اپ: CameraX + MediaPipe Face Landmarker، TTS، Room، DataStore، رابط کاربری Compose راست‌به‌چپ |

## ساخت

```bash
cd app
# تست منطق اصلی (بدون Android SDK):
./gradlew -PcoreOnly=true test
# ساخت APK (نیاز به Android SDK با platform 35؛ ANDROID_HOME یا local.properties):
./gradlew :android:assembleDebug
```

فایل مدل `face_landmarker.task` داخل `android/src/main/assets` است، پس تشخیص چهره آفلاین کار می‌کند.

## راهنمای سریع برای همراه بیمار

1. تبلت را روبه‌روی صورت بیمار، با فاصله‌ی ۴۰ تا ۶۰ سانتی‌متر، ثابت کنید. نور صورت کافی باشد.
2. **تنظیمات** را باز کنید (دکمه‌ی ⚙ را نگه دارید) و **کالیبراسیون** را اجرا کنید. راهنما با صدا گفته می‌شود: ۴ ثانیه چشم باز و نگاه به وسط، بعد ۳ ثانیه چشم بسته.
3. در **صفحه‌ی عیب‌یابی** ببینید نمودار پلک با بستن چشم از خط قرمز بالاتر می‌رود.
4. **پلک ارادی:** چشم را بین ۰٫۴۵ تا ۲ ثانیه بسته نگه دارید. در لحظه‌ی بستن، اسکن می‌ایستد. وقتی بوق «آماده» پخش شد، با باز کردن چشم گزینه انتخاب می‌شود. پلک کوتاه نادیده گرفته می‌شود. بسته ماندن طولانی (خواب) چیزی را انتخاب نمی‌کند.
5. **کمک فوری** آژیر پخش می‌کند، حتی در حالت بی‌صدا. فقط همراه بیمار می‌تواند آن را قطع کند: دکمه را ۲ ثانیه نگه دارد.
6. **استراحت:** برای برگشتن، ۳ پلک ارادی در ۵ ثانیه لازم است.
7. **سؤال پرسیدن:** دکمه‌ی 🎤 را بزنید و سؤال را بپرسید. سؤال بله/نه صفحه‌ی بله/نه را باز می‌کند و سؤال درباره‌ی درد، صفحه‌ی درد را.

هیچ تصویری از دوربین ذخیره یا ارسال نمی‌شود. فریم‌ها فقط در حافظه تحلیل و بلافاصله دور ریخته می‌شوند.
