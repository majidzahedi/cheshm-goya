# چشم‌گویا

سیستم ارتباطی برای بیمارانی که نمی‌توانند حرف بزنند یا دستشان را حرکت دهند، ولی می‌توانند پلک بزنند و چشمشان را حرکت دهند. مثلاً بیماران ALS، سکته‌ی مغزی یا زیر ونتیلاتور. کل رابط کاربری فارسی و راست‌به‌چپ است.

```
app/     اپ اندروید تبلت بیمار — بخش اصلی؛ کاملاً آفلاین و بدون سرور کار می‌کند
server/  سرور هوش مصنوعی روی کامپیوتر GPU‌دار خودتان — لایه‌ی اختیاری
```

**اصل طراحی:** هر قابلیت هوش مصنوعی یک لایه‌ی اضافه است. اگر سرور یا اینترنت در دسترس نبود، اپ بی‌صدا به حالت آفلاین برمی‌گردد و هیچ چیزی از کار نمی‌افتد. هر درخواست timeout دارد: ۱ ثانیه برای رتبه‌بندی و ۳ ثانیه برای تولید متن.

- راهنمای اپ: [app/README.md](app/README.md)
- راهنمای سرور، انتخاب مدل‌ها و امنیت: [server/README.md](server/README.md)

## قابلیت‌های اصلی

- **تشخیص پلک ارادی:** حداقل و حداکثر مدت بسته ماندن قابل تنظیم است. سیگنال هموار می‌شود و هیسترزیس دارد. مهلت واکنش ۳۰۰ میلی‌ثانیه‌ای دارد، بوق «آماده» پخش می‌شود و نوار پیشرفت روی گزینه پر می‌شود. می‌شود هر دو چشم یا فقط یک چشم را انتخاب کرد. کالیبراسیون با راهنمای صوتی انجام می‌شود.
- **روش‌های ورودی:**
  - اسکن خودکار (سطر-ستون برای صفحه‌های بزرگ، خطی برای لیست‌های کوتاه)
  - حرکت با نگاه به چپ و راست
  - کلید: لمس، کلیدهای صدا، کلید بلوتوثی و صفحه‌کلید
  - خواندن بلند گزینه‌ها برای بیمار کم‌بینا
- **صفحه‌ها:**
  - صفحه‌ی اصلی با جای ثابت دکمه‌ها
  - دسته‌های عبارت و مقیاس درد ۰ تا ۱۰
  - صفحه‌کلید کامل فارسی با دو چینش
  - «عبارت‌های من» با خروجی و ورودی JSON
  - کمک فوری با آژیر و پیامک اختیاری
  - حالت استراحت و تاریخچه
- **پیش‌بینی آفلاین:** کامل کردن کلمه، پیش‌بینی کلمه‌ی بعدی با n-gram دوتایی و سه‌تایی، و جمله‌های کامل. از هر جمله‌ای که بیمار می‌گوید یاد می‌گیرد.
- **هوش مصنوعی اختیاری:** سرور محلی خودتان، Jev (فقط برای رتبه‌بندی) یا Claude. در تنظیمات قابل انتخاب است و پیش‌فرض آن خاموش است.
